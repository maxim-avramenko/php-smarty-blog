# Тестовое задание: блог на PHP + Smarty + MySQL

Источник требований для этого репозитория. Реализация остаётся в рамках этого документа: чистый PHP без фреймворков, Smarty, MySQL.

## Цель

Простой, полностью рабочий сайт блога с категориями и статьями.

## Технологический стек

- PHP 8.1+
- Шаблонизатор Smarty
- MySQL
- Без фреймворков

Будет плюсом:

- SCSS для стилей
- Docker-окружение

## Структура данных

### Категория

- Название
- Описание

### Статья

- Изображение
- Название
- Описание
- Текст
- Категория: одна или несколько
- Количество просмотров

## Обязательные страницы

### Главная

- Вывести каждую категорию, в которой есть статьи.
- В каждой такой категории показать 3 последних поста по дате публикации.
- Для каждой категории показать кнопку «Все статьи».

### Страница категории

- Название и описание категории.
- Список статей.
- Сортировка статей: по количеству просмотров и по дате публикации.
- Пагинация.

### Страница статьи

- Вся информация о статье.
- Блок из 3 похожих статей.

## Дополнительный функционал

- Сидинг категорий и статей.

- Структура проекта
