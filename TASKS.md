# Задачи: блог на PHP + Smarty + MySQL

Источник требований — [TASK.md](TASK.md). Этот файл фиксирует разбиение на задачи и решения, согласованные для реализации.

Админки и форм создания постов в задании нет: публичный сайт только для чтения, данные только из сида.

Окружение уже есть и в эти задачи не входит: Docker, внешний Traefik, заглушка `public/index.php`.

## Зафиксированные решения

- Адреса: `/`, `/category/{id}`, `/article/{id}`. Сортировка и страница: `?sort=date|views&page=2`.
- Идентификаторы числовые, без слагов.
- Front controller без фреймворка и без своего роутера: nginx отдаёт ЧПУ в `index.php`.
- У статьи есть `published_at`: без даты нельзя выбрать три последних поста и сортировать по дате публикации.
- Похожие статьи — другие статьи с общей категорией. Сначала с большим числом совпавших категорий, затем более новые. Если общих меньше трёх, блок короче, без добора «просто последних».
- Пагинация: 6 статей на страницу. По умолчанию сортировка по дате публикации, новые сверху.
- Просмотры: `+1` на каждый GET страницы статьи, без кук и дедупликации.
- Картинки: путь в БД, файлы в `public/uploads`. Сид кладёт свои заглушки и не зависит от внешних URL в рантайме.
- SCSS: небольшой набор стилей, скомпилированный CSS в `public`.

## Задачи

1. **Схема MySQL.** Таблицы `categories`, `articles` и связка `article_category` (у статьи одна или несколько категорий). У статьи поля из задания плюс `published_at`.
2. **Каркас приложения.** Front controller, подключение к MySQL, Smarty, общие layout-шаблоны.
3. **Запросы.** Категории, в которых есть посты; три последних поста категории; список категории с сортировкой и пагинацией; статья со всеми категориями; три похожих.
4. **Сид.** Несколько категорий и статей, в том числе категория без постов (на главной её быть не должно) и статьи с несколькими категориями. Картинки — локальные файлы в `public/uploads`.
5. **Главная.** Каждая категория, где есть статьи; внутри — три последних поста по `published_at`; кнопка «Все статьи».
6. **Страница категории.** Название, описание, список статей, сортировка по просмотрам и по дате, пагинация.
7. **Страница статьи.** Все поля, категории, картинка. Отдельный заход увеличивает счётчик просмотров на 1. Блок из трёх похожих.
8. **Вёрстка.** Общий layout и SCSS, скомпилированный CSS в `public`.
